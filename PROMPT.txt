1. Coding
Please write a python program that does audit log filtering by the given date range.
The input can be a .tar.gz archive or a folder; same for the output.
Recursively iterate through each item in the input:
- if an item is an archive, unpack every items inside, process, and pack back, recursively.
- if an item is a text file, process every line
- if an item is a compressed text file, decompress, process every line, and compress back
- otherwise, leave it as it is

Support the following line formats containing datetime:
a. dpkg log
2026-05-12 18:47:39 startup packages remove

b. auditd log
type=CWD msg=audit(1779039207.533:33367473): cwd="/home/zhao/Desktop/diseaseProject"

c. boot log
------------ Tue May 12 18:45:08 +08 2026 ------------

d. apt history log
Start-Date: 2026-05-12  18:50:47
End-Date: 2026-05-12  18:50:51

e. apt term log
Log, some tar archives can be huge, do not wait for full extraction, start processing whenever
- Make your code generic and compatible with as many formats as possible. If it crashes on a line, ignore the line, leave it as it is.
- If the entire file content all lies outside the date range, output the empty file.
- Print progress using '\r' to avoid massive scroll, output warnings/errors if any.
- cmdline argument must support ISO8601 including bare date format: "2026-02-01" (assuming current timezone) started: 2026-05-12  18:47:39
...

f. auth log (missing year number means this year):
Jan  1 08:00:45 ...
2026-05-18T16:12:12.044297+08:00 ...


General guidelines:
- Keep the code as short as possible.
- Every text input file can have a mixture of timestamp line formats, do not assume a single format throughout the whole file.
- Support multiple CPU cores, some tar archives can be huge, do not wait for full extraction, start processing whenever any file is available. Thus, you need to track global worker processes count.
- Make your code generic and compatible with as many formats as possible. If it crashes on a line, ignore the line, leave it as it is in the output.
- If the input file is empty or all its content lies outside the date range, output the empty file.
- Print progress using '\r' to avoid massive scroll, output warnings/errors if any.
- cmdline argument must support ISO8601 including bare date format: "2026-02-01" (assuming current timezone)


2. Debugging
Use `/opt/anaconda3/bin/python` to test your python code on `./input` for the given date range from 2026-02-01 to 2026-05-15, use `./output` for output folder:
```
/opt/anaconda3/bin/python filter-audit.py input output --start 2026-02-01 --end 2026-05-15 -j 8
```
Examine every output file to make sure it is correct. Fix bugs if any.
